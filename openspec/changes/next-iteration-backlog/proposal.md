> 需求清单的正式版本在 `docs/roadmap.md`。本目录只保留需要走 OpenSpec 流程的那部分。

## Why

首轮交付已完成，但有三块功能与原版的差距仍然明显，且在实现前需要先想清楚产品方向，不适合继续边写边改。本轮把它们从当前变更中下线，集中记录在这里，等设计定稿后再动手。

## What Changes

现阶段**不改动代码**。本变更只是需求收拢：把三项已确认要做、但形态尚未定稿的功能记入待办，并说明每项为什么被推迟、需要先决定什么。

### 已从本期下线

- **统计数据**：当前实现是 Swift Charts 的简易柱状图 + 环形图，与原版差距很大。原版包含"在电脑前总时长 / 每天均值 / 每个工作日均值"的汇总、"平均工作/平均休息"折线叠加、三张环形图（工作休息比、今日一览、休息取消占比）、以及按时段分布的第二组柱状图。需要先定数据口径与视觉方案。
- **高级配置**：当前实现只覆盖空闲暂停、前台应用、唤醒重置、铃声、背景亮度五项，布局与原版不一致（原版是按"休息前几秒 / 开始休息 / 完成休息 / 锁屏"分组的密集表单）。需要先按原版分组重排。

### 新记录的需求

- **全屏休息的自定义背景**：当前遮罩是纯色（或桌面截图降级）。考虑支持用户自选图片作为休息背景。
- **检查更新**：轻量版已在 1.0.0 交付（读公开 gist 的版本清单 → 比较 → 给下载链接）。Sparkle 自动更新仍未做，见 `docs/roadmap.md` 的 P2。

## Capabilities

### New Capabilities

- `statistics-redesign`: 统计窗口的完整重构，含汇总文案、混合图表、三张环形图与时光分布柱状图
- `advanced-settings-redesign`: 高级配置窗口按原版分组重排，补齐休息前提示、指示器、铃声选择、锁屏亮度与预览
- `overlay-custom-background`: 休息遮罩支持用户自选图片作为背景

### Modified Capabilities

- `break-overlay`: 背景来源从"桌面截图或纯色"扩展为"桌面截图 / 纯色 / 用户图片"三选一

## Impact

**代码**：`Sources/BreatherCore/StatsStore.swift` 保留（数据层不变，只换展示）；统计与高级配置的窗口控制器在本期已删除，下期重建；`BreakOverlayController` 需增加背景来源分支。

**设置项**：本期已实现但暂时没有界面的项——`pauseWhenFrontmost`、`frontmostApps`、`pauseWhenIdle`、`idleMinutes`、`resetWhenWakeup`、`captureDesktopImage`、`overlayBrightness`、铃声音量——逻辑保留，下期随高级配置窗口一起接回界面。

**没有纳入的问题**：原版的 Pro 内购（新版不复刻）。

## Open Questions

- 统计的"工作日"口径：原版按 weekday 分组，是否需要排除某些工作日
- 自定义背景是全局一张，还是可按时间段/阶段区分
- 高级配置里的"隐藏锁屏屏幕窗口"在原版是可选行为，是否需要保留该开关
