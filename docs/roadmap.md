# 二期需求清单

1.0.0 已交付：计时循环、菜单栏饼图、主面板、全屏休息遮罩、偏好设定、中英切换、签到式检查更新。

下面是第二期要做的事。按优先级排列，优先级只看"不做会不会影响日常使用"。

---

## P0 统计窗口重做

**为什么**：1.0.0 把统计窗口下线了，现在应用完全不记录可视化的使用情况。数据层一直在跑（按分钟记录工作/休息），只是没有界面。

**要做什么**

- 汇总区：在电脑前总时长、每日均值、每个工作日均值
- 主图表：7 天柱状图，叠加"平均工作 / 平均休息"两条折线，双 Y 轴
- 三张环形图：工作休息比、今日一览、休息取消占比
- 时段分布：24 小时内按小时堆叠的柱状图
- 交互：上下方向键切周，S 键导出 PNG

**前置**：确认"工作日"的定义——是否排除周末，跨天如何切分。

**验收**：连续使用三天后，四块图表的数据与 `StatsStore` 记录一致；切换周时数据随之变化。

---

## P0 高级配置窗口重做

**为什么**：1.0.0 把高级配置下线，但底层逻辑（空闲暂停、前台应用暂停、唤醒重置、铃声、遮罩亮度）全都在跑，只是没有界面可以改。

**要做什么**

- 按"休息前提示 / 开始休息 / 完成休息 / 锁屏"分组排布，而不是现在的平铺
- 补齐：休息前几秒的阈值、状态栏指示器开关、铃声选择与试听、锁屏亮度实时预览
- 前台应用名单的增删（当前只能添加，不能逐条删除）

**前置**：确认"隐藏锁屏屏幕窗口"这个开关是否保留——1.0.0 里遮罩行为是固定的。

**验收**：每个开关改动后立即生效；重启后保持；空闲 5 分钟能自动暂停并在回到键鼠后恢复。

---

## P1 休息遮罩支持自定义背景

**为什么**：现在遮罩是纯黑或桌面截图。自定义图片不需要屏幕录制权限，又能让"被迫停下来"这件事有正反馈。

**要做什么**

- 设置里选择图片文件，支持铺满/适应两种填充方式
- 保持现有降级：没设图片时用纯色；开了桌面截图且无权限时退回纯色
- 深色文字与浅色文字的自动对比度处理

**前置**：定清楚是全局一张，还是按阶段/时间段区分；大图如何存储（拷进容器还是只存路径）。

**验收**：设置一张 4K 图片，两块屏幕上都正确铺满且不拉伸变形；删掉源文件后不崩溃、回退纯色。

---

## P2 检查更新升级为自动更新

**为什么**：现在只是"发现新版本 → 给个链接"，用户还要手动下载、替换、重启。

**前提**：Sparkle 需要稳定的代码签名身份来校验更新来源。1.0.0 已经用免费的 Apple Development 证书签名，具备 Team ID，理论上可行；但要先确认 Sparkle 2 在非 Developer ID 签名下的行为。

**要做什么**：接入 Sparkle 2、生成 appcast、配置 EdDSA 密钥、在 CI 里给每次发布签名更新包。

**风险**：如果 Sparkle 要求 Developer ID，这条路就断了，需要重新评估是否值得买证书。

---

## P3 其他候选（未定优先级）

- 更多语言（当前只有中英）
- 系统通知（休息开始时发一条，替代全屏遮罩的轻量模式）
- 休息时锁定系统（调用系统屏保/锁屏，代替自制遮罩）

---

## 明确不做

- Pro 内购与付费墙
- 云同步、账号体系
- App Store 上架（需要沙盒 + 审核 + 付费账号）
